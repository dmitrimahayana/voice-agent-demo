# Demo 1: Bright Smile Dental AI receptionist (Vapi)

Ava answers every call for a fictional dental clinic. She books, reschedules and cancels on a live Cal.com calendar, answers insurance and price questions from the clinic info, flags emergencies, transfers to a human, and logs every call to a Google Sheet.

**Buyer:** clinic and practice owners, and agencies selling to them. It sits closest to the real Retell + GoodX work.

## Files
| File | What it is |
|---|---|
| `prompt.md` | System prompt (edit this) |
| `knowledge-base.md` | Clinic facts, inlined into the prompt at build time |
| `assistant.vapi.json` | Generated by `scripts/build-configs.mjs`; don't edit by hand |
| `test-script.md` | 26 calls to pass before recording |

## Setup (about 1.5 hours)
1. **Cal.com (free):** create an event type "Dental appointment", 30 minutes, with your availability. Copy the event type ID into `CALCOM_EVENT_TYPE_ID` in `functions/wrangler.toml`. Create an API key under Settings > Developer > API keys and save it with `wrangler secret put CALCOM_API_KEY`.
2. Deploy the Worker (root README).
3. Build the config: `WORKER_URL=… WEBHOOK_SECRET=… node scripts/build-configs.mjs`. Set `TRANSFER_NUMBER` to your own phone for the human-handoff test.
4. **Vapi:** sign up (no card), then either run the script with `--push` or create an assistant in the dashboard and paste the matching sections from `assistant.vapi.json`.
5. **Number:** in Vapi, go to Phone Numbers > Import > Twilio, enter your Twilio number, Account SID and Auth Token, then assign this assistant to it. The same number also places Demo 3's outbound calls.
6. Run all 26 calls in `test-script.md` and fix the prompt until each one passes.
7. Optional browser calls: put your Vapi **public** key and the assistant ID into `hub/index.html`.

## What to show in the video
A live call next to the Cal.com bookings page (the booking appears), then the emergency path, then the Google Sheet row with the summary.

## Free-tier notes
- Each call costs about $0.07 to $0.12 per minute from the $10 credit. Calls are capped at 3 minutes.
- Bookings are keyed by the caller's phone number, because phone callers rarely give an email. Cal.com needs an email, so the Worker uses a placeholder address like `caller-15125550142@example.com`.
