## Portfolio entries (pin 1 and 2)

### 1. AI Dental Receptionist that books on a live calendar (24/7 demo)
- **Role:** Voice AI developer, solo build
- **Description:** Demo AI receptionist for a dental clinic. Answers calls 24/7; books, reschedules and cancels on a live calendar; answers insurance and pricing FAQs; flags emergencies and texts the front desk. Every call is logged with intent, outcome and summary. Built on Vapi with a Cloudflare Worker, Cal.com and Google Sheets. The video shows a live call to the demo line.
- **Media:** 90-second video, booking screenshot, call-log screenshot
- **Skills:** Vapi, AI Voice Agent, Conversational AI, ElevenLabs, API Integration

### 2. GoHighLevel AI Voice Agent for Home Services (white-label ready)
- **Role:** Voice AI and GHL developer
- **Description:** Retell voice agent that qualifies plumbing and HVAC callers, triages emergencies, and writes contact, custom fields, tags, notes and bookings into GoHighLevel during the call. GHL workflows text the on-call tech for emergencies and confirm bookings to the customer. Packaged as a reusable setup that agencies clone for each sub-account.
- **Media:** split-screen video (call plus GHL), pipeline screenshot
- **Skills:** Retell AI, GoHighLevel, Voice AI, Workflow Automation, CRM Integration

### 3. Speed-to-Lead AI Callback in Under 60 Seconds (multi-client template)
- **Role:** Automation architect
- **Description:** A web lead triggers an AI outbound call in about 30 seconds. One prompt template serves many businesses, and each client is one config row (name, offer, questions, calendar). The agent references what the lead wrote, qualifies in three questions and books. Outcomes and summaries are logged for the client. Built for agencies that resell AI calling.
- **Media:** video of form submit to phone ringing, config sheet screenshot
- **Skills:** Vapi, n8n, Twilio, Lead Generation Automation, AI Agent Development

### 4. Retell AI to GoodX booking integration (client work)
- **Role:** Integration developer
- **Description:** Write this from the real project: the problem, what the agent books, how it talks to GoodX, and one result number. Anonymize it as "medical practice" unless the client agrees to be named.
- **Skills:** Retell AI, API Integration, Healthcare Scheduling
